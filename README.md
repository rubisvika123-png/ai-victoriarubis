# Личный AI-агент в Telegram — без программирования

Готовая заготовка. Скачиваешь, вписываешь два своих значения (токен бота и свой
Telegram ID) — и у тебя личный AI-агент, который отвечает тебе в Telegram
обычными словами. **Код писать не нужно.**

---

## Что это

Личный AI-ассистент, который:

- живёт у тебя на компьютере;
- общается в Telegram как живой собеседник, а не бот по кнопкам;
- понимает обычный язык — пишешь словами, он отвечает.

Это основа (Урок 1). На следующих уроках научим его помнить контекст, отвечать
«как ты» и работать в связке с другими агентами.

---

## Что нужно для старта

- **Компьютер** — Windows или Mac. Подойдёт личный: агент работает, пока
  компьютер включён (про режим «всегда онлайн» — в конце).
- **Подписка Claude** — это «мозг» агента. Хватит **Pro ($20/мес)**; для
  плотной ежедневной работы удобнее **Max ($100/мес)**.
- **Аккаунт Telegram.**
- **Около часа времени.**
- **Если ты в России** — VPN, чтобы открывался сайт Claude.

> **Про деньги — честно.** Агент работает в обычной сессии Claude Code под твоей
> подпиской Pro/Max. Это не отдельный платный API и не headless-режим —
> отдельного счёта не появляется, расходуются обычные лимиты подписки. Пока
> агент просто включён и ждёт — он не тратит ничего; лимиты идут только когда он
> реально отвечает на сообщения.

---

## Шаг 1. Поставить Claude Code

Это программа, через которую агент живёт на компьютере. Ставится один раз.

1. Открой терминал: на Mac — программа «Терминал», на Windows — «PowerShell».
   Это окно для команд: мы даём готовые строки, ты копируешь и жмёшь Enter.
2. Установи Claude Code (нужен Node.js 18 и новее):

   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

   > Нет Node.js? Поставь его с https://nodejs.org (кнопка LTS) и повтори команду.

3. Войди в свой аккаунт Claude:

   ```bash
   claude
   ```

   Откроется вход через браузер (тут и нужен VPN, если ты в РФ). После входа
   окно можно закрыть — главное, что вход выполнен.

✅ Проверка: команда `claude` запускается.

---

## Шаг 2. Создать бота в Telegram

Бот — это «лицо» агента в Telegram.

1. Найди в Telegram **@BotFather** (официальный бот).
2. Отправь ему `/newbot`.
3. Придумай имя бота и его адрес (он заканчивается на `bot`).
4. BotFather пришлёт **токен** — длинную строку вида `8976066018:AAH...`.
5. Скопируй токен и никому не показывай — это ключ от бота, как пароль.

✅ Проверка: токен у тебя на руках.

---

## Шаг 3. Скачать заготовку

Вариант А — командой (git обычно уже стоит вместе с Claude Code):

```bash
git clone https://github.com/rubisvika123-png/ai-victoriarubis.git
cd ai-victoriarubis
```

Вариант Б — кнопкой: на странице репозитория нажми **Code → Download ZIP**,
распакуй и открой папку.

✅ Проверка: на компьютере есть папка `ai-victoriarubis`.

---

## Шаг 4. Вписать токен и свой Telegram ID

1. Узнай свой **Telegram ID** — это число (не телефон и не @username): напиши в
   Telegram боту **@userinfobot**, он пришлёт твой `Id`.
2. Скопируй образец настроек и убери из имени «.example»:

   ```bash
   cp secrets/channel.env.example secrets/channel.env
   ```

3. Открой `secrets/channel.env` в любом текстовом редакторе и заполни:
   - `TELEGRAM_BOT_TOKEN` — токен из Шага 2;
   - `TELEGRAM_EXPECTED_BOT_ID` — цифры из токена **до двоеточия**;
   - `TELEGRAM_ALLOWED_USER_IDS` и `TELEGRAM_ALLOWED_CHAT_IDS` — твой ID из п.1.
4. Сохрани файл. Больше ничего менять не нужно.

✅ Проверка: в `secrets/channel.env` вписаны токен и твой ID.

> Файл `channel.env` остаётся только у тебя на компьютере и никуда не
> выкладывается.

---

## Шаг 5. Поставить зависимости движка (один раз)

```bash
cd dashi-plugin-claude-code/plugin
bun install
cd ../..
```

> Нет команды `bun`? Поставь его: `curl -fsSL https://bun.sh/install | bash`
> (на Mac можно `brew install bun`), затем повтори `bun install`.

✅ Проверка: `bun install` прошёл без красных ошибок.

---

## Шаг 6. Запустить агента

Из папки `ai-victoriarubis`:

```bash
./start.sh
```

Агент «просыпается»: Claude Code запускается и начинает слушать Telegram. Это
окно держи открытым — пока оно открыто, агент бодрствует.

> При первом запуске Claude Code может один раз спросить подтверждение режима
> работы — согласись (вариант «Yes»).

✅ Проверка: в окне видно, что агент запущен.

---

## Шаг 7. Написать боту

1. Открой Telegram, найди своего бота (по адресу из Шага 2).
2. Напиши ему: **«Привет, ты кто?»**
3. Через пару секунд агент ответит сам.

🎉 Готово — у тебя работает личный AI-агент в Telegram.

---

## Если не работает

1. **Бот молчит.** Окно из Шага 6 закрыто? Закрыл окно — агент уснул. Проверь
   также, что в токене нет лишних пробелов.
2. **`claude: command not found` или `bun: command not found`.** Установка из
   Шага 1 или Шага 5 не завершилась — повтори её и открой терминал заново.
3. **Не открывается вход в Claude.** Включи VPN (если ты в РФ) и попробуй снова.
4. **`start.sh` пишет, что нет `secrets/channel.env`.** Ты не скопировал
   `channel.env.example` в `channel.env` (Шаг 4, п.2).
5. **Бот не отвечает на твои сообщения.** Проверь, что в
   `TELEGRAM_ALLOWED_USER_IDS` стоит именно твоё число из @userinfobot, а не
   @username и не телефон.

## Где держать агента

- **На своём компьютере (по умолчанию).** Самый простой старт. Минус: агент
  работает только пока компьютер включён и окно `start.sh` открыто.
- **Тихий домашний мини-компьютер, включённый всегда** — тогда агент отвечает
  круглосуточно.
- **Арендованный сервер (VPS) 24/7** — для «всегда онлайн» без своего железа.
  Настройка как сервиса разбирается на курсе.
