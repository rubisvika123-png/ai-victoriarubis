# Свой AI-агент в Telegram — за один вечер, без строчки кода

Перед тобой готовый набор файлов. Ты скачиваешь его, вписываешь всего два своих
значения — и получаешь собственного помощника, который переписывается с тобой в
Telegram живым языком. Программировать не нужно ни минуты.

## Как это устроено — в двух словах

Три части, соединённые вместе:

- **Telegram** — окно, через которое ты пишешь и получаешь ответы.
- **Мост** (папка `dashi-plugin-claude-code`) — переносит твои сообщения туда и
  обратно.
- **Claude** — думающая часть, которая читает сообщение и сочиняет ответ.

Ты общаешься как с обычным собеседником: пишешь словами — получаешь словами.
Никаких кнопок и команд.

## Что нужно приготовить

| Что | Зачем |
|-----|-------|
| Компьютер с Windows или macOS | На нём агент и живёт; работает, пока компьютер включён |
| Подписка Claude | Думающая часть агента. Хватит **Pro ($20/мес)**; при активном использовании удобнее **Max ($100/мес)** |
| Telegram | Через него идёт переписка |
| Примерно час свободного времени | На всю сборку с нуля |
| VPN — если ты в России | Понадобится, чтобы открылся сайт входа в Claude |

## Сколько это стоит на самом деле

Отдельного счёта не будет. Агент живёт внутри обычной сессии Claude Code и
расходует ту же подписку Pro или Max, которой ты пользуешься лично. Это не
платный API и не серверный режим — просто твои обычные лимиты. Причём тратятся
они только в моменты, когда агент реально отвечает; пока он включён и молча ждёт
сообщения, расхода нет.

---

Дальше — сборка. Она делится на две части: сначала один раз ставим инструменты,
потом собираем самого агента.

## Часть первая. Ставим инструменты (делается один раз)

### Claude Code

Это программа, внутри которой агент существует на компьютере.

1. Открой окно для команд: на macOS — «Терминал», на Windows — «PowerShell».
   Дальше мы будем давать готовые строки — ты их вставляешь и жмёшь Enter.
2. Убедись, что стоит Node.js версии 18 или новее (если нет — возьми на
   https://nodejs.org, кнопка LTS). Затем установи саму программу:

   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

3. Войди в свой аккаунт Claude — просто запусти:

   ```bash
   claude
   ```

   Откроется вход через браузер (здесь и пригодится VPN, если ты в России). Как
   только вошёл — вкладку можно закрывать.

Готово, если команда `claude` запускается.

### Бот в Telegram

Бот — это адрес, по которому ты будешь писать своему агенту.

1. Найди в Telegram аккаунт **@BotFather** — это официальный бот Telegram для
   создания ботов.
2. Отправь ему команду `/newbot` и следуй подсказкам: придумай название и адрес
   (адрес обязан оканчиваться на `bot`).
3. В ответ придёт **токен** — длинная строка вроде `8976066018:AAH...`. Держи
   его при себе и никому не показывай: это ключ от бота.

Готово, если токен у тебя на руках.

## Часть вторая. Собираем агента

### Забираем заготовку к себе

Через команду (git ставится вместе с Claude Code):

```bash
git clone https://github.com/rubisvika123-png/ai-victoriarubis.git
cd ai-victoriarubis
```

Либо без команд: на странице проекта нажми зелёную кнопку **Code → Download
ZIP**, распакуй и открой получившуюся папку.

### Вписываем свои два значения

Всё, что агенту нужно лично про тебя, — это токен бота и твой номер в Telegram.

1. Узнай свой **Telegram ID**. Это именно число, а не телефон и не @-имя. Напиши
   боту **@userinfobot** — он пришлёт строку `Id` с этим числом.
2. Сделай себе рабочий файл настроек из образца:

   ```bash
   cp secrets/channel.env.example secrets/channel.env
   ```

3. Открой `secrets/channel.env` любым текстовым редактором и заполни четыре
   строки:
   - `TELEGRAM_BOT_TOKEN` — токен бота из прошлого шага;
   - `TELEGRAM_EXPECTED_BOT_ID` — та часть токена, что стоит **перед
     двоеточием** (только цифры);
   - `TELEGRAM_ALLOWED_USER_IDS` и `TELEGRAM_ALLOWED_CHAT_IDS` — твой Telegram ID
     из первого пункта.
4. Сохрани. Остальное трогать не надо.

Этот файл никуда не выкладывается и остаётся только на твоём компьютере.

### Ставим движок

Одна разовая установка зависимостей моста:

```bash
cd dashi-plugin-claude-code/plugin
bun install
cd ../..
```

Если команды `bun` нет — поставь её: `curl -fsSL https://bun.sh/install | bash`
(на macOS подойдёт и `brew install bun`), потом повтори `bun install`.

### Запускаем

Из корневой папки `ai-victoriarubis`:

```bash
./start.sh
```

Claude Code стартует и начинает слушать Telegram. Это окно оставь открытым —
пока оно живёт, живёт и агент. При самом первом запуске программа может один раз
спросить разрешение на режим работы; согласись («Yes»).

### Проверяем

Открой Telegram, найди своего бота по адресу из первой части и напиши что-нибудь,
например «Привет, кто ты?». Через пару секунд агент ответит сам. Если ответил —
всё собрано верно.

## Что делать, если не отвечает

- **Молчит.** Скорее всего закрылось окно `./start.sh` — без него агент спит.
  Проверь заодно, не затесались ли лишние пробелы в токене.
- **`command not found` (claude или bun).** Установка соответствующего
  инструмента не дошла до конца. Повтори её и открой окно команд заново.
- **Не грузится вход в Claude.** Включи VPN (для России) и попробуй ещё раз.
- **Ругается на отсутствие `secrets/channel.env`.** Ты пропустил шаг с
  копированием образца — сделай `cp secrets/channel.env.example
  secrets/channel.env`.
- **Отвечает не тебе или игнорирует.** В `TELEGRAM_ALLOWED_USER_IDS` должно
  стоять твоё число из @userinfobot, а не @-имя и не телефон.

## Где агенту жить дальше

- **Прямо на твоём компьютере** — самый простой вариант для старта. Минус один:
  работает, только пока компьютер включён и окно запуска открыто.
- **Маленький компьютер, который всегда включён** (тихий домашний мини-ПК) — тот
  же агент, но отвечает круглые сутки.
- **Арендованный сервер (VPS)** — «всегда онлайн» без собственного железа.
  Настройку постоянной работы разбираем на курсе.

## Сменить думающую модель

По умолчанию агент думает на Claude из твоей подписки. Позже его можно
переключить на более быструю и дешёвую модель или подключить запасную — на
случай перебоев. Это тема отдельного урока.

## Куда двигаться после

- **Урок 2** — характер и память: агент учится отвечать в твоём стиле и помнить,
  о чём вы говорили. Заготовки `CLAUDE.md` и папка `core/` для этого уже лежат в
  наборе.
- **Урок 4** — запасной движок и смена думающей модели.
